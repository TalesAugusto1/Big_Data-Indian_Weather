Introdução:

O projeto final do curso de Big Data tem como objetivo permitir que os alunos apliquem os conhecimentos adquiridos durante o semestre em um projeto prático e desafiador. Neste projeto, vocês trabalharão em equipes de três pessoas para desenvolver sistemas de analise de dados com tecnologias de Big Data que envolvem análise exploratória de dados (EDA), pré-processamento e modelos preditivos.  Neste projeto, vocês trabalharão em equipes de quatro pessoas para desenvolver sistemas de IA.

 

Descrição do Projeto:

Vocês têm a liberdade de escolher uma base de dados de sua preferência no Kaggle, na qual o conjunto de dados destinado à tarefa pode ser do tipo regressão ou classificação, a escolha ficará po conta da equipe. Vocês devem dividir o projeto em três partes principais:

 

Parte 1: Construção de um Ambiente de Big Data -> 1 pontos

Nesta parte do projeto, vocês irão construir um ambiente de big data com ecossitema Apache, utilizando o docker para simular um sistema de cluster de big data. 

 

Parte 2: Tarefa de Analise de dados -> 5 pontos

Nesta parte do projeto, vocês selecionarão uma base de dados adequada para uma tarefa de regressão ou classificação. Alguns exemplos incluem previsão de preços de imóveis, previsão de vendas, ou qualquer conjunto de dados que envolva a previsão de um valor numérico para tarefa de regressão ou classificação de produtos, avaliação de sentimentos em revisões, ou qualquer conjunto de dados de classificação de interesse. Unico pré-requisito é que o dataset precisa ter mais de 1Gb de dados. Vocês seguirão os seguintes passos:

Seleção de Dados: Escolha uma base de dados apropriada no Kaggle para a tarefa de classificação. A base precisa passar por uma aprovação do professor.

Pré-processamento: Realize o pré-processamento de dados, tratamento de desequilíbrio de classes e outras etapas relevantes.

Análise Exploratória de Dados (EDA): Realize uma análise exploratória dos dados para extrair insights e entender a distribuição das classes.

 

Parte 3: Tarefa de Previsão -> 4 pontos

Nesta parte do projeto, vocês iram realizar o treinamento desses algoritmos de aprendizado de maquina: Decision Tree, Linear Regression (ou Logistic Regression) e Redes Neurais. Vocês seguirão os seguintes passos:

Modelos de Regressão: Implemente os 3 modelos de predição destinados a tarefa selecionada na parte 2, para prever o valor-alvo.

Avaliação e Apresentação: Avalie o desempenho dos modelos e prepare uma apresentação detalhando o processo, os resultados e as conclusões.

 

Apresentação Final do projeto dia: 11/05, 13/05 , 25/05 e 27/05 :

Cada equipe de alunos apresentará seus resultados e conclusões em uma apresentação final. A apresentação deve incluir demonstrações práticas dos modelos, análises de resultados, desafios enfrentados e sugestões para melhorias futuras. A avaliação levará em consideração tanto o desempenho dos modelos quanto a qualidade da apresentação.

Este projeto final permitirá que vocês escolham conjuntos de dados que despertem seu interesse e apliquem uma ampla gama de técnicas de Big Data junto a analise de dados e modelos de predição aprendidas ao longo do curso. Além disso, a apresentação final desenvolverá suas habilidades de comunicação e apresentação, essenciais em sua carreira de engenheiros de Dados.
